# Asset Sources

Provenance for third-party assets bundled into the game.

## How to use

- When adding a new asset, add a new entry in the sources table below.
- When updating an asset, do not keep previous entry, update the existing one.
- Assets that do not require attribution still need to be recorded here.
- Do not add extra information to this file.
